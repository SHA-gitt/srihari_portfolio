Torch Motion Ecosystem

Python PyQt5 PyOpenGL ESP32 Arduino Shapely
~/WAAM_Robot/

About: Torch Motion is a motion control ecosystem developed for custom-built MIG-based Cartesian robot, Centre for Railway Research, IIT Kharagpur. Purpose built for WAAM applications, the ecosystem includes a purpose-built path programming language, ToM Code, tailored for WAAM applications and customizable for different use cases, along with a ToM Slicer that generates toolpaths from STL files and compiles them into executable ToM Code. A digital twin of the firmware is developed to validate programs prior to execution, improving reliability and reducing hardware trial-and-error. Additionally, a G-code to ToM Code compiler ensures compatibility with existing 3D printing workflows, while support for multiple end-effectors such as a laser profilometer and plasma torch enables broader manufacturing applications.

Purpose: To learn and develop a cost effective motion control system feasible for research purposes by overcoming the high licensing cost, limited adaptability, and vendor dependency of commercially available WAAM systems.
