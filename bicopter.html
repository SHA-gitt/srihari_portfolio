Sim-to-Real: Bicopter Flight Controller Tuning

Isaac Sim CATIA V5 Python Microcontroller
~/Virtual_Robotic_Training/

About: This is a learning project to understand and get hands on experience on the robotics training pipeline. In this project, a bicopter test rig is designed for its simpler dynamic model than quadcopter. It is designed in CATIA V5 and using mesh lab software inertial mass tensor and other physical properties such as center of mass and radius of gyration are calculated and added to the bicopter's URDF model. A PID controller is developed using python and the system is imported to virtual robot training environment. For this project, NVIDIA Isaac Sim is used and the PID controller is tuned in this simulator. Finally the tuned controller is deployed on actual hardware for real-time validation using a microcontroller.

Purpose: To learn by building an complete robot training pipeline from scratch. From CAD modeling to URDF generation, developing PID based control system with python, tuning PID controller in physics simulator such as NVIDIA Isaac Sim and deploying the controller on actual hardware for real-time validation.
