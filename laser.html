Laser profilometer

OpenCV NumPy Raspberry Pi
~/Profile_Extraction/

About: Laser profilometry is a non-contact optical metrology method used to measure the surface topography of objects, in this case, weld bead width and height. It uses a line laser to scan across the surface, and a camera to capture the reflection of the laser line from the surface. This laser and camera setup is mounted on the custom built Cartesian robot, at Center for Railway Research, IIT Kharagpur, and can be prompted for selective capturing of specified number of cross sectional images via ToM Code. The captured images are stored in a tree-branch structure for batch processing. The tree folder and process parameter directory is fed to the script that processes all the images sequencially and extracts the weld bead geometry and generates a dataset with specimen number, bead width and bead height and respective process parameter.

Purpose: To develop an autonomous measurement system for given deposition region and also to generate dataset containing process parameter and bead geometry features to train a Physics Informed Neural Network (PINN) model to predict the process parameter for repairing worn out rail surface in railway tracks using WAAM.
